# Cross-genre holdout B v2

Date completed: 2026-09-02

Decision: **the frozen DrumScribe rhythm-completion hybrid passed the limited
90% cross-genre lab target and exceeded Drum2Notes on the same 12 full
mixtures.** DrumScribe reached **97.35% six-family micro F1 at 20 ms**, versus
**65.54%** for Drum2Notes. Every individual DrumScribe genre score was above
90%.

This is a rights-cleared, deterministic, single-kit synthetic benchmark. It is
not evidence of 90% accuracy on arbitrary released music and does not clear the
production license or general-song release gates.

| Metric | DrumScribe | Drum2Notes |

| Six-family micro F1, 20 ms | **97.35%** | 65.54% |
| Six-family precision, 20 ms | **98.99%** | 72.36% |
| Six-family recall, 20 ms | **95.76%** | 59.90% |

| Six-family micro F1, 50 ms | **97.35%** | 84.87% |
| Detailed-class micro F1, 50 ms | **96.80%** | 70.57% |

The primary metric is event-level micro F1 over kick, snare, hi-hat, cymbal,
tom and tambourine families with a strict 20 ms onset tolerance. The detailed
metric preserves supported articulations and tom classes.

## What changed

The existing `drumscribe-hybrid-v1` detector remains responsible for observed
hits. A new confidence-gated rhythm stage then:

- refines the Beat This tempo map from reliable kick anchors;
- independently reconstructs a cumulative kick grid so one missed tracker beat
  cannot shift the rest of a chart;
- completes only strongly repeated hi-hat, ride and backbeat patterns;
- preserves detected articulations and crash evidence; and
- returns the detector output unchanged when a stable grid cannot be proved.

The API enables this stage only for the explicit `drumscribe_hybrid` provider.
Sparse, rubato and unstable-tempo inputs therefore do not receive invented
regular grooves from this stage.

## Protocol

- Twelve new 20-second arrangements cover soft pop, rock, hard rock, metal,
  punk, funk, disco, hip-hop, R&B, jazz, country and electronic music.
- Compositions and backing audio were generated by project code. Drums use the
  MuldjordKit FreePats samples under CC BY 4.0.
- Holdout B uses different deterministic seeds, tempos and arrangements from
  development and Holdout A.
- References were written and hashed before separation or inference. The
  implementation was frozen before Holdout B prediction and was not changed in
  response to its scores.
- Both systems received the same full-mix WAV files. Drum2Notes was run on
  2026-09-02 using Multi-Instrument, Drums, All drumset and automatic advanced
  settings. Its free demo evaluated the same first 20 seconds.
- Both raw outputs were converted to the same canonical taxonomy and scored by
  the same one-to-one onset matcher at 20 ms and 50 ms.

The compact machine-readable evidence is in
`docs/benchmarks/data/CROSS_GENRE_HOLDOUT_B_V2.json`. Local raw evidence is in
`output/cross-genre-holdout-b-v2-2026-09-02/competitor-comparison.json`.

## Remaining release boundary

The six-family macro F1 is 95.36%, but the detailed-class macro F1 is only
84.77%. Crash, cross-stick, individual toms and open hi-hat remain below 90% on
this small-support suite. Repetitive synthetic grooves and a single known kit
also make this task easier than live, expressive or mastered commercial music.

Before advertising broad 90% accuracy or enabling paid production inference,
DrumScribe still needs a large, rights-cleared, multi-kit human-performance
holdout; isolated-stem and full-mixture evaluation; sufficient support for
every canonical class; and approval of all model, training-data and separation
licenses. The 99% release gate remains unchanged.
